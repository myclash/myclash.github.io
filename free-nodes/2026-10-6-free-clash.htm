什么是 Clash？

Clash 的核心概念

Clash 是一款开源的跨平台网络代理工具，支持Shadowsocks、VMess（V2Ray）、Trojan 等多种协议，能够通过自定义路由规则，实现智能分流，优化网络体验。其最大的亮点在于：

✅ 智能路由：支持策略分流，可以为不同的网站和应用指定不同的代理方式。
✅ 多协议支持：可以同时使用多个代理节点，适配各种网络环境。
✅ YAML 配置文件：通过修改 YAML 文件，用户可以完全掌控代理的行为。
✅ 跨平台兼容：支持 Windows、macOS、Linux，甚至 Android 和 iOS（需额外配置）。

相比于 Shadowsocks、V2Ray 等工具，Clash 提供了更加灵活的规则管理，能够根据需求定制不同的代理模式，从而实现更快、更稳定、更智能的网络连接。

Clash 汉语的基本配置

Clash 的配置核心是 YAML 配置文件。所有的代理服务器、规则、策略等，均通过 config.yaml 进行设置。

首次配置向导

1️⃣ 启动 Clash 汉语，进入配置页面。
2️⃣ 输入代理服务器信息（如服务器地址、端口、加密方式等）。
3️⃣ 选择合适的代理模式（全局模式 / 规则模式 / 直连模式）。
4️⃣ 保存配置并测试连接。

Clash 配置文件解析（config.yaml）

Clash 的配置文件使用 YAML 格式，以下是一个基本的 config.yaml 示例：

yaml
proxies:
  - name: "香港服务器"
    type: vmess
    server: hk.example.com
    port: 443
    uuid: 12345678-abcd-1234-efgh-9876543210
    alterId: 64
    cipher: auto

proxy-groups:
  - name: "自动选择"
    type: select
    proxies:
      - "香港服务器"
      - "日本服务器"

rules:
  - GEOIP,CN,DIRECT
  - MATCH,自动选择

? proxies：定义可用的代理服务器。
? proxy-groups：设置代理策略，如“自动选择最快服务器”。
? rules：定义访问规则，如国内流量直连，国外流量代理。

FAQ

Hiddify Next 如何实现用户流量分配？
管理员可为每个用户设置带宽和流量配额。超出限制时可自动降速或阻止访问，确保服务器资源合理分配，避免单用户占用过多带宽，提高整体网络公平性和效率。
Hiddify Next 的多用户限速功能如何使用？
Hiddify Next 支持在管理面板中为每个用户设置带宽上限。管理员可以按需分配速率或流量配额，防止单一用户占用过多资源，从而保持整体网络稳定。
WinXray 的主要特点是什么？
WinXray 是一款基于 V2Ray 核心的 Windows 客户端，界面直观，支持 VMess、VLess、Trojan、Shadowsocks 等多协议。它提供一键导入订阅、节点测速、自动分流等功能，是适合初学者和进阶用户的图形化代理工具。
QuantumultX 与 Shadowrocket 相比的最大区别是什么？
QuantumultX 在规则系统和自动化脚本上更灵活，支持丰富的 rewrite 与 filter 功能，而 Shadowrocket 则更轻便易用，适合普通用户快速切换节点。二者可根据使用习惯与功能需求选择。
Trojan 的伪装域名有什么要求？
Trojan 的伪装域名必须是可以通过 HTTPS 正常访问的真实网站，并且 SSL 证书有效。伪装域名用于与服务器证书匹配，使得流量在外观上完全与正常 HTTPS 请求一致。
VLESS + XTLS 在高延迟网络中如何优化连接？
XTLS 模式通过减少握手和加密开销降低延迟。结合策略组和多节点切换，可在高延迟或不稳定网络环境下保证网页浏览、视频播放和游戏连接稳定，提高用户体验。
Surfboard 的规则文件如何支持广告屏蔽？
规则文件可添加广告域名或 URL 列表，将请求重定向或阻断。结合策略组和自动更新，Surfboard 可实现全局广告屏蔽，提高浏览体验并节省带宽。
Vmess 与 Trojan 哪个更快？
在相同环境下，Trojan 通常连接更快，因为它使用原生 TLS 通道；Vmess 则稍有额外的协议开销。但在配置合理的情况下，两者的速度差距不大，主要取决于服务器线路质量。
如何配置 Sing-box 使用 DoH 加密 DNS？
在 dns 模块中添加类型为 doh 的上游，如 `https://1.1.1.1/dns-query`，并指定 bootstrap 地址。启用加密 DNS 可防止 DNS 泄露并加快国际解析速度，提高整体隐私保护。
Netch 如何选择全局代理与规则代理模式？
全局代理适合所有流量走节点，如游戏和全局科学上网；规则代理仅针对指定应用、IP 或端口走节点，可优化带宽使用和访问效率，根据使用场景选择模式。
